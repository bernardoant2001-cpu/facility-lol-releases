# Facility LOL

Entre na fila, aceite partidas, escolha campeões e aplique a build do League of Legends pelo celular.

## 1. No PC

**[Baixar o FacilityLOL.exe](https://github.com/bernardoant2001-cpu/facility-lol-releases/releases/latest/download/FacilityLOL.exe)**

1. Crie uma pasta (ex.: `D:\Aplicativos\Facility LOL`) e coloque o `FacilityLOL.exe` nela.
2. Abra o `FacilityLOL.exe`. O painel abre no navegador com um passo a passo.
3. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
4. Se o Windows perguntar sobre o firewall, permita em **redes privadas**.

O Facility LOL roda em segundo plano, sem janela. Para fechar, use **Encerrar** no painel.

## 2. No celular

- **Android:** instale o app **[FacilityLOL.apk](https://github.com/bernardoant2001-cpu/facility-lol-releases/releases/latest/download/FacilityLOL.apk)** (o painel do PC mostra um QR code para baixar). Se o celular pedir, permita instalar apps desta fonte.
- **iPhone:** não precisa instalar nada. Abra o link do painel no **Safari** e toque em **Compartilhar → Adicionar à Tela de Início** para ter o ícone.

Depois, é só apontar a câmera para o QR code do painel e tocar em **Abrir com Facility LOL**. No Android, permita as notificações: o app avisa quando a partida aparecer, com **Aceitar** e **Recusar** na própria notificação.

As automações (aceitar, escolher e banir) rodam no PC, então funcionam mesmo com o celular longe. O painel do PC também tem um botão para controlar tudo por lá.

## Atualizações

Toda vez que você abre o `FacilityLOL.exe`, ele confere se tem versão nova aqui, baixa, confere o arquivo e reinicia sozinho. As telas do celular vêm do PC, então também se atualizam juntas.

## Privacidade

Tudo roda no seu PC e na sua rede Wi-Fi. Cada instalação cria a própria chave de acesso, então ninguém controla o seu cliente pelo celular de outra pessoa.

Projeto pessoal, sem vínculo com a Riot Games. Usa a API local do cliente do LoL, que não tem suporte oficial da Riot e é proibida no servidor coreano.
